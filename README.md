# WUF Predict

Sistema de apoyo predictivo para WUF . Este estima probabilidades de adopción, alerta de los estados desactualizados para su revisión y segmenta perfiles desfavorecidos mediante herramientas y algoritmos de ML.

Para conocer el proyecto y ponerlo en marcha, consulta estas guías:

- [Contexto del sistema](CONTEXTO_SISTEMA.md): propósito, módulos, roles y estructura.
- [Guía de inicio local](GUIA_INICIO_LOCAL.md): configuración y ejecución en tu equipo.
- [Guía de la base de datos](GUIA_BASE_DE_DATOS.md): instalación, tablas y relaciones.

El sistema está desarrollado con una interfaz web, una API en Python con FastAPI y una base de datos PostgreSQL. Sus modelos ayudan a priorizar la difusión, revisar el catálogo y reconocer grupos de mascotas con características similares.
